# Key Notions

* Agent
   * Rationale: The Person taking part in the study.
   * Connected Pattern: Agent Role(MODL)
* Measure
  * Rationale: Phenomenon being measured. (Physiological Measure, Performance Measure).
  * Connected Pattern : Taxonomy Alignment(Physiological Measure)(MODL)
    
* ~~Physiological Measure~~
   * ~~Rationale: Type of physiological phenomenon being measured. (Heart Rate, Respiratory Rate etc.)~~
 
* ~~Performance Measure~~
   *~~Rationale: Type of performance phenomenon being measured. (Altitude, Speed, Direction etc.)~~
  
* Behavioral State
  * Rationale: State experienced/observed during a session/task. (Flow, Fatigue)
       
* Survey
  *  Rationale: Questionnaire administered to the participant. 
    
* Wearable
  * Rationale: Physical sensing device worn by a participant. (Garmin, Oura, Pupil Labs Eye Tracker)

* Sensor
     * Rationale: Wearable Sensing component that collects measurements. (PPG, ECG, Eye Tracker)
     * Connected Pattern : Observation (MODL), Sensor(SOSA/SSN)
       
* Session
     * Rationale: A period of data collection for a participant.
     * Connected Pattern : Identifier, TemporalExtent (MODL)

* Task
   * Rationale : Activity performed by a participant. (Playing games, Flights, Drive)
     
* Measurement
  * Rationale : Observation made from Sensor
  * Connected Pattern : Observation, Data Transformation, Temporal Extent (MODL)
 
* Goal
  * Rationale : Ultimate outcome of all tasks performed.
 
* Role
  * Rationale : Agent's title while performing a task.
  * Connected Pattern : Agent-Role(MODL)
    
* Wear Location
  * Rationale : Identify the location where we wear the wearable device.
    
* Equipment
  * Rationale : Machinery used to perform the task. (Plane, Race car, Computer)
